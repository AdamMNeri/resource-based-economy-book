# RBE Book Project Review Runbook

This runbook provides a structured approach for you, Adam, to review new content and changes generated by the daily RBE Book Development cron job and to provide feedback.

## Purpose

To ensure the quality, accuracy, and alignment of the generated RBE book content with your vision, and to facilitate an efficient review and feedback loop.

## Prerequisites

*   **Obsidian:** Ensure your Obsidian application is configured to open the vault at `/home/neria/Drive-Vaults/RBE_Book_Vault`.
*   **Git (Recommended):** For robust version control and easy comparison of changes, it is highly recommended to initialize a Git repository in your project directory:

```bash
cd /home/neria/code_projects/rbe-book && git init && git add . && git commit -m "Initial commit of RBE book project"
```

    *Please ensure your global Git identity is configured with `git config --global user.email "your_email@example.com"` and `git config --global user.name "Your Name"` before attempting to commit.*

## Reviewing New Work

The daily cron job will update the Markdown files within the `/home/neria/code_projects/rbe-book/chapters/` and potentially the `README.md`.

### Method 1: Using Obsidian (Recommended for content review)

1.  **Open Obsidian:** Navigate to your RBE Book Vault in Obsidian (`/home/neria/Drive-Vaults/RBE_Book_Vault`).
2.  **Browse Chapters:** Open the chapter files within the `chapters/` subfolder.
3.  **Review Changes:** Read through the updated or newly generated content. Obsidian's linking capabilities will help you navigate related concepts.
4.  **Add Notes/Feedback:** You can create new notes in Obsidian to capture your thoughts, questions, or feedback, linking them to the specific chapter or section using `[[Chapter Name#Section]]` syntax.

### Method 2: Using the Terminal (Recommended for quick checks and diffs)

1.  **Navigate to Project Directory:**
    ```bash
    cd /home/neria/code_projects/rbe-book
    ```
2.  **View Changes (if Git is configured):**
    *   To see a summary of all changes since your last commit:
        ```bash
        git status
        ```
    *   To view detailed differences for a specific file (e.g., `chapters/chapter-1-the-case-for-change.md`):
        ```bash
        git diff chapters/chapter-1-the-case-for-change.md
        ```
    *   To view changes across all modified files:
        ```bash
        git diff
        ```
3.  **Read Files Directly:**
    ```bash
    read_file chapters/chapter-1-the-case-for-change.md
    ```
    (Replace with the actual chapter file you want to review.)

## Providing Feedback and Guidance

Once you've reviewed the content, provide your feedback directly to me in the chat. Be as specific as possible. Examples:

*   "For Chapter 3, expand on the role of UNCTAD in facilitating technology transfer."
*   "The explanation of 'Economic Calculation Problem' in Chapter 2 needs more detail on real-world examples."
*   "I disagree with the framing of [specific point] in Chapter X. Let's rephrase it to [suggested rephrase]."
*   "Please incorporate more research on [specific topic] into Chapter Y, using sources [Source A], [Source B]."

## Iteration and Approval

1.  **Iterative Refinement:** I will use your feedback to refine the content, conduct further research, and generate new drafts.
2.  **Final Approval:** Once a chapter or section meets your approval, you will explicitly confirm it. At that point, I will consider that content "final" for a version and we can proceed with integrating it into the larger book structure. If Git is in use, this would typically involve a commit after your approval.

## Automated Local Build & Remote Web Server Deployment

Upon every completion of the `rbe-book-authoring` workflow, Hermes automatically executes:
1. **Local Static Reader Build**: Runs `make build` locally in `~/code_projects/rbe-book/` to refresh the local `book/` static html directory without spinning up a local web server.
2. **Remote Deployment to capevm1**: Syncs updated codebase files via `rsync` to `neria@192.168.85.105:/home/neria/services/rbe-book/`, runs `make build` remotely, and restarts the live web server on port 3000 via `bash start_server.sh`.
3. **Live Reader URL**: The updated reader edition is immediately viewable on your home network at:
   `http://192.168.85.105:3000`

## Checking Cron Job Status and Logs

To monitor the daily cron job's activity:

1.  **List Cron Jobs:**
    ```python
    print(default_api.cronjob(action='list'))
    ```
    This will show you the status of the "RBE Book Daily Development" job, including its last run time and next scheduled run.

2.  **View Cron Job Logs:**
    ```python
    print(default_api.cronjob(action='log', job_id='be90e99d36d5'))
    ```
    This will display the output of the most recent cron job run, which can provide insights into what actions it took and what content it generated.
